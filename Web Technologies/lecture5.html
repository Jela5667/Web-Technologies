Lecture 5: CSS Basics and Selectors

CSS syntax, selectors and pseudo-classes

Summary

This lecture explains how CSS separates content from design. It covers CSS syntax, inline, internal and external CSS, the types of selectors, and pseudo-classes and pseudo-elements.

Topics Covered

  • CSS Syntax
    • Selector, property and value
    • Inline, Internal and External CSS
  • Selectors
    • Element, Class and ID
    • Attribute and Grouping
    • Descendant, child and sibling
    • Universal selector
  • Pseudo-classes and Pseudo-elements
    • :hover, :focus, :nth-child()
    • ::before, ::after, ::first-letter

Example Code

h1 { color: teal; }
.highlight { background: yellow; }
#title { font-size: 30px; }

Output

This heading is teal

This paragraph has a yellow background
