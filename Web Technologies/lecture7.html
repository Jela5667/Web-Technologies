Lecture 7: Responsive Web Design

Media queries and flexible layouts

Summary

This lecture explains how to make a web page look good on all screen sizes using the viewport tag, relative units and media queries.

Topics Covered

  • Responsive Basics
    • Viewport meta tag
    • Relative units: %, em, rem
    • Media queries

Example Code

@media (max-width: 600px) {
  body { font-size: 14px; }
}

Output

On small screens the text becomes smaller.
