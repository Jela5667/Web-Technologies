Lecture 6: CSS Text Properties and Box Model

Cascade, colors, fonts, backgrounds and box model

Summary

This lecture covers how the browser chooses between CSS rules (cascade, specificity, inheritance), the color, font, text and background properties, and the box model with padding, border, margin and the display property.

Topics Covered

  • Cascade and Specificity
    • ID is stronger than class, class is stronger than element
    • Inheritance
  • Text and Background
    • HEX, RGB and RGBA colors
    • font-family, font-size, font-weight
    • text-align, line-height, background
  • Box Model
    • Content, Padding, Border, Margin
    • box-sizing: border-box
    • display: block, inline, inline-block, none

Example Code

.box {
  width: 250px;
  padding: 20px;
  border: 2px solid teal;
  margin: 10px;
}

Output

A box with padding, border and margin
